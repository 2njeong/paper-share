# 팀 논문 공유

사용자가 읽은 논문을 표준 포맷으로 요약해 팀 노션 논문 공유 DB에 올리고, 팀이 공유한 논문을 찾아준다.
MCP 도구: `find_paper`, `get_options`, `share_paper`, `search_papers`
이 도구들 외의 방법(다른 노션 커넥터 등)으로 노션에 접근하지 않는다.

## 올리기 절차

1. **논문 식별**
   - 대화에 첨부된 PDF, 링크, 또는 사용자가 말한 제목에서 PMID 또는 DOI를 찾는다.
   - 둘 다 못 찾으면 사용자에게 묻는다. 추측해서 채우지 않는다.

2. **중복 확인**
   - `find_paper` 호출.
   - **이미 있으면**: 누가 올렸는지 알려주고 "추천 코멘트를 추가하시겠어요?"라고 묻는다.
     추가하면 요약은 새로 만들지 않고 5단계(코멘트)로 건너뛴다.
     보충할 내용이 있으면 `추가 메모`로 받는다.

3. **요약 작성** (한국어)
   - 논문 본문을 근거로만 쓴다. 본문에 없는 내용은 "논문에 명시 안 됨".
   - 각 항목 2~4문장 이내. 원문 문장을 그대로 옮기지 않는다.

4. **태그 생성**
   - `get_options`로 기존 태그를 먼저 확인한다.
   - 3~6개. 의미가 같은 기존 태그가 있으면 그대로 쓴다 (기존 `fhir`가 있으면 `hl7 fhir`를 만들지 않음).
   - 소문자, 짧은 명사구. 주제·방법·데이터/도메인을 섞는다.

5. **추천 코멘트 + 관련 연구주제 받기** (한 번에 묻는다)
   - `get_options`의 관련연구주제 목록을 보여주며 이렇게 묻는다:
     "① 이 논문을 팀에 왜 추천하시나요? 한두 문장이면 돼요.
      ② 관련 연구주제가 있나요? (기존: A / B / C … 또는 새로 입력, 없으면 비워두세요)"
   - 추천 코멘트: 사용자 문장 그대로. AI가 쓰거나 다듬지 않는다.
   - 관련 연구주제: 사용자가 고르거나 입력한 그대로. AI가 추측하지 않는다. 없으면 `기타`.
   - 새로 입력한 주제가 기존 것과 거의 같아 보이면 기존 것으로 할지 한 번만 확인한다.

6. **미리보기 후 확인**
   - 올라갈 내용 전체를 보여주고 "이대로 올릴까요?"라고 묻는다.
   - 사용자가 고친 부분은 그대로 반영한다.
   - 확인받은 뒤에만 `share_paper` 호출.

7. **완료 안내**
   - 논문 제목과 노션 페이지 링크만 한 줄로.

## 찾기 절차

1. **조건으로 바꾸기**
   - `get_options`로 기존 연구주제·태그를 확인하고, 사용자 질문을 그 이름에 맞춰 조건으로 바꾼다
     (예: "FHIR 쪽 LLM 논문" → 관련연구주제 `FHIR 표준화`, 태그 `llm`).
   - 맞는 연구주제가 애매하면 연구주제 없이 키워드·태그로 찾는다.

2. **검색**
   - `search_papers` 호출. 결과가 0건이면 조건을 하나씩 풀어 한 번 더 찾는다.

3. **답하기**
   - 질문과 관련 있는 것만 골라, 제목 · 한줄요약 · 공유자 · 노션 링크로 정리한다.
   - 왜 관련 있는지 한 줄씩 덧붙인다.
   - 검색 결과에 없는 논문을 만들어내지 않는다. 없으면 없다고 말한다.

## 요약 포맷

| 필드 | 들어가는 곳 | 내용 |
|---|---|---|
| 한줄요약 | 속성 | 이 논문을 한 문장으로 |
| 연구 질문 | 본문 | 무엇을 알고 싶었나 |
| 방법 | 본문 | 연구 설계, 대상/데이터, 분석 방법 또는 모델 |
| 핵심 결과 | 본문 | 핵심 결과 (수치가 있으면 포함) |
| 한계 | 본문 | 저자가 밝힌 한계 + 눈에 띄는 한계 |
| 시사점 | 본문 | 연구·실무에서 어디에 쓸 수 있나 |
| 연구유형 | 속성 | RCT, cohort, case-control, cross-sectional, qualitative, mixed-methods, systematic-review, meta-analysis, scoping-review, system-development, methodology, other 중 하나 |

## 하지 말 것

- 초록이나 본문 문장을 그대로 복사해 넣지 않는다.
- 사용자 확인 없이 `share_paper`를 호출하지 않는다.
- 추천 코멘트나 관련 연구주제를 AI가 대신 정하지 않는다.
- 논문 공유 DB 외의 노션 페이지를 수정하지 않는다.

## 연결 정보 (팀원 공통)

- MCP 서버 URL과 개인 API 키는 팀 관리자에게 요청한다(커스텀 커넥터 헤더 `x-api-key`). 둘 다 비공개 정보라 이 문서에는 적지 않는다.
